## Implemented source

- Removed the unused runtime completeness registry, its regression/task and the
  zero-deferred release gate. Inventory retains source hashes and bootstrap decisions:
  347 authorities, 55 domain entries, 43 optional domains. This is not a capability count.
- Added Self navigation for session, mode, one-use arming, own character, current
  world, nearby AREA, Thread Case and durable history. AREA inspection is bounded
  to 32 entities and 9 chunks. Catalog Threads require a compatible importer.
- PvE Imprint copies only rank, archetype, known template reference and the native
  eligible/capped ability kit. It uses the existing temporary combat projection.
- Native PvE Fork starts nonpersistent, inert and invulnerable; the source is read-only.
  Committed event/entity quarantine precedes combat activation. Session admission is
  capped at 16; native expiry is 120 seconds. Cleanup checks exact native origin.
  The final review tightened explicit removal: its receipt now requires synchronous
  owner-local observation that the entity is invalid. Queued session cleanup remains
  asynchronous. The native probe rejects a wrong origin and observes exact removal.
- Developer Binding uses the journal projection authority: AREA entry → recipient
  VFX, 16 executions, 2-second cooldown, 120-second expiry. Session retirement and
  sever stop dispatch; there is no arbitrary action graph or recursion.
- Limited Event provider uses four native gathering-window kinds, available catalog,
  active identity, SANDBOX/LIVE start and expected-instance stop. Native sandbox
  windows provide no bonus drops or XP multiplier. Other event families are optional.
- Trash uses existing item actions/Undo plus owned immediate Anomaly presentation
  previews and three native sandbox rule-field kinds. Fields last 20 seconds, have
  radius 3 and a session cap of 16; retired callbacks cannot publish fields.
- Minecraft retains useful inspection/pulse and guarded LIVE game-mode mutation;
  removed the unused materials catalog and unconsumed location Thread export.
- Existing Faction/Territory projections and native canonical mutations remain.
  Itemization retains ten actions and nine conditional native inverses.
- Artifact registration is enabled for the primary developer. Durable actions require
  successful startup/recovery, journal readiness and an open runtime. Coverage is not
  an activation gate. Existing actor/session/arming checks remain mandatory.

preserves pause, including the pending-Fork quarantine window. There is no second

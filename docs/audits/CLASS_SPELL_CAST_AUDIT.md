## Proven BLOCKER/HIGH fixes

- SpellRegistry duplicate IDs are fail-fast via first-registration preservation; silent overwrite is removed.
- Typed `Spell.cast(Player, CastModifiers)` is the shared canonical execution path; legacy scalar compatibility delegates one-way into typed cast.
- Standard power is semantically separated: damage/healing/shield magnitude may scale, while hard-CC duration does not inherit mastery/level/gear/damage power implicitly.
- Failed validation, PREPARING, NO_TARGET and non-committing execution paths remain transaction-neutral for class commit/cooldown/combo/stat bookkeeping.
- `ConfiguredSpell` freeze + Slowness uses a single lazy DR factor for one spell execution instead of consuming two DR steps.
- Delayed/projectile scaling is snapshot-based across scheduler hops. Hardening explicitly covers projectile burst, Glaive Throw, Angry Chicken, Mind Blast, Deep Breath, Whirlwind, Flying Serpent Kick and Shaman totem pulse damage.
- Shaman totem owner cleanup despawns the live ArmorStand/pulse projection instead of only dropping the owner map.
- DARK/loadout runtime reconciliation despawns transient minion projections, preserves durable Profile v2 companion state, clears illegal selected spell state while sealed, and deterministically reconciles selection after a usable rebuild.
- Druid player-facing naming is distinct: primary `Természeti Erő`, secondary `Harmónia`; the machine ID remains `harmony`.
- Invalid generic combo chains `soul-collapse` and `way-of-hundred-fists` were removed and are semantic deny-list entries for strict validation.

## Cast architecture

Final flow:

`INPUT → AUTHORITY / ACTIVE KIT → SPELL RESOLVE → VALIDATION → PREPARATION → MODIFIERS → AFFORDABILITY / RESERVATION → TYPED EXECUTION → STATE COMMIT → COOLDOWN → FEEDBACK / STATS`

Invariants:

- validation/preparation cannot silently spend committed class state;
- PREPARING is not a successful cast;
- modifier calculation is side-effect free;
- successful execution commits exactly once;
- a non-committing outcome does not start cooldown or write cast history/statistics;
- delayed output must snapshot the semantic modifiers before leaving the synchronous cast context;
- PlayerProfile/ClassSpec is the durable authority; combat, pet/minion/totem and spell runtime objects are projections.
